# FullStage — Approved Branding

**Identity:** Ribbon Spotlight F · **Product:** FullStage, Open Presenter Software  
**Tagline:** Every Screen. Every Moment. · **Approved:** November 2026

This folder is the canonical location for the approved, user-supplied FullStage branding images. Preserve the source PNGs unchanged (including their alpha channels). The original files are packaged in the companion Git-ready branding ZIP.

## Brand usage

- Use the full lockup for websites, splash screens, documentation, and marketing.
- Use symbol-only marks for desktop launchers, mobile remote, favicon, and taskbar.
- Do not distort, rotate, recolor, or add effects to the approved emblem.
- Test small-icon legibility at 16, 24, 32, 48, 64, and 128 px.
- Export platform-specific launcher formats separately (`.ico`, `.icns`, Linux PNG) and verify each. The approved source artwork does not by itself establish an installer.
- Retain the distinction between this approved FullStage brand and the upstream FreeShow application identity.

**Integration note:** PNG source artwork must be uploaded as binary files. GitHub's text-file connector can maintain this index but cannot ingest the conversation's PNG bytes; do not mistake the existence of this index for binary assets having been committed.
