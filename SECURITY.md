# Security policy

FullStage is **pre-alpha**. Do not rely on it in safety-critical live events, broadcast environments, or unattended production without independent testing.

For security concerns, use GitHub's private vulnerability reporting if enabled, or contact repository maintainers privately rather than publishing exploit details. Avoid posting credentials, tokens, private presentation data or copyrighted media to public issues.

Network remote control must default to local-only access, explicit pairing/authorization, and the least permissions necessary. Audit any future plugin, external media API, OSC/MIDI or WebSocket integration for unsafe input and privilege boundaries.
